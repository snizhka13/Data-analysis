# Data-analysis: Інтерактивний веб-додаток для інтелектуального аналізу даних

Цей репозиторій містить веб-додаток, створений за допомогою фреймворку **Streamlit** мовою Python. Проєкт розроблено як сучасну, гнучку та програмовану альтернативу десктопним інструментам (таким як Orange) для виконання завдань з інтелектуального аналізу даних (Data Mining) та машинного навчання (Machine Learning).

Додаток дозволяє завантажувати власні набори даних (CSV) або використовувати вбудовані (Titanic, Iris, Penguins) для проведення комплексного аналізу в інтерактивному режимі.

## Функціонал (Модулі додатку)

Додаток складається з 6 основних модулів, між якими можна перемикатися за допомогою бічної панелі:

1. **Описова статистика (Descriptive Statistics)**
   * Перегляд структури та типів даних.
   * Автоматичний розрахунок базових статистичних метрик (середнє, медіана, мінімум/максимум, квартилі).
   * Побудова гістограм розподілу для числових змінних.

2. **Пошук асоціативних правил (Association Rules)**
   * Реалізація алгоритму **Apriori** для пошуку частих наборів предметів (Frequent Itemsets).
   * Інтерактивне налаштування параметрів *min_support* та *min_confidence*.
   * Розрахунок метрик Support, Confidence та Lift.
   * Візуалізація правил за допомогою діаграми розсіювання (Scatter plot).

3. **Комплексний кластерний аналіз (Clustering)**
   * **Ієрархічна кластеризація:** побудова дендрограм з можливістю порівняння різних мір відстаней (Евклідова, Манхеттенська) та методів об'єднання (Метод Варда, найближчого/найвіддаленішого сусіда).
   * **Алгоритм k-середніх (K-Means):** визначення оптимальної кількості кластерів методом "ліктя" (Elbow method), розподіл об'єктів та візуалізація профілів кластерів.

4. **Факторний аналіз (Factor Analysis)**
   * Перевірка придатності даних: Критерій Кайзера-Мейєра-Олкіна (KMO) та критерій сферичності Бартлета.
   * Визначення кількості факторів за допомогою графіка "кам'янистого осипу" (Scree Plot).
   * Побудова факторної моделі з використанням різних методів обертання (Varimax, Promax, Oblimin).
   * Аналіз факторних навантажень та спільностей.

5. **Порівняння моделей класифікації (Classification)**
   * Інтерактивний поділ даних на навчальну (Train) та тестову (Test) вибірки.
   * Одночасне навчання та порівняння 4 алгоритмів: Decision Tree, Random Forest, Logistic Regression, Naive Bayes.
   * Оцінка моделей за метриками: Accuracy, Precision, Recall, F1-score, MCC та AUC.
   * Побудова Матриці помилок (Confusion Matrix) та ROC-кривих.

6. **Аналіз текстів (Text Mining)**
   * Автоматичний парсинг статей з Вікіпедії за пошуковим запитом (українською або англійською).
   * Попередня обробка тексту та фільтрація (Stopwords) з можливістю додавання користувацьких стоп-слів.
   * Візуалізація результатів за допомогою Хмари слів (Word Cloud).
   * Розрахунок міри TF-IDF для виділення найважливіших слів.
   * Пошук контексту (Concordance) для заданих ключових слів.

## Технологічний стек

* **Мова:** Python 3.9+
* **Фреймворк:** Streamlit
* **Обробка даних:** Pandas, NumPy
* **Машинне навчання та статистика:** Scikit-learn, SciPy, mlxtend, factor_analyzer
* **Візуалізація:** Matplotlib, Seaborn, WordCloud
* **Збір даних:** Wikipedia API
