# Веб-додаток для описової статистики

Цей проєкт — інтерактивний веб-додаток для проведення базового розвідувального аналізу даних (EDA) та отримання описової статистики. Створений за допомогою мови Python та фреймворку Streamlit.

## Основні можливості

*   **Аналіз власних даних:** Підтримка завантаження користувацьких файлів у форматі `.csv`.
*   **Вбудовані набори даних:** Доступ до класичних тестових датасетів з бібліотеки Seaborn (наприклад, *titanic, iris, tips, penguins*).
*   **Інтерактивний перегляд:** Відображення даних у вигляді зручної таблиці з можливістю скролінгу та сортування, а також автоматичний вивід типів змінних та розмірності датасету.
*   **Описова статистика:** Автоматичний розрахунок ключових статистичних метрик (середнє, медіана, мінімум, максимум, стандартне відхилення, квартилі) для всіх числових змінних.
*   **Візуалізація розподілу:** Побудова гістограм з кривою щільності розподілу (KDE) для будь-якої обраної числової змінної.

## Використані технології

*   **Python** — основна мова програмування.
*   **Streamlit** — створення веб-інтерфейсу.
*   **Pandas** — обробка та маніпуляція даними.
*   **Seaborn & Matplotlib** — побудова статистичних графіків.
