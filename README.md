Назва репозиторію: Data-analysis

Опис (Description):

Інтерактивний веб-додаток для базового аналізу даних та візуалізації, створений за допомогою Python та Streamlit. Додаток дозволяє швидко досліджувати набори даних, автоматично генерувати описову статистику та будувати графіки розподілу. Розроблено в рамках виконання лабораторної роботи з аналізу даних.

Основний функціонал (Features):

Завантаження власних наборів даних у форматі .csv.

Використання вбудованих навчальних датасетів з бібліотеки Seaborn (наприклад, titanic, iris, penguins тощо).

Інтерактивний перегляд даних у вигляді таблиці з можливістю сортування.

Автоматичне визначення розмірності таблиці (кількість рядків та стовпців) та типів змінних.

Миттєва генерація описової статистики для всіх числових змінних (середнє, медіана, стандартне відхилення, мінімум, максимум та квартилі).

Побудова гістограм та кривих щільності розподілу для обраних користувачем змінних.

Технологічний стек (Tech Stack):

Мова: Python

Інтерфейс: Streamlit

Обробка даних: Pandas

Візуалізація: Seaborn, Matplotlib

Як запустити локально:

Bash
# Клонувати репозиторій
git clone https://github.com/snizhka13/Data-analysis.git

# Встановити залежності
pip install -r requirements.txt

# Запустити додаток
streamlit run app.py
